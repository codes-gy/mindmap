# 브라우저에는 탭의 뼈대만 보내고, 전체 노트는 따로 둔다

마인드맵과 진도 계산은 브라우저에서 돌지만, 여기에 필요한 것은 개념의 id, 슬러그, 제목, 심화 표시뿐이다. 그래서 클라이언트 컴포넌트에는 `skeleton()`이 만든 뼈대만 넘기고, 개념 본문은 서버에서 HTML로 그린다(`lib/content.ts`). 탭 화면이 그 탭의 모든 설명을 함께 그리던 때는 `/cs` HTML이 4.4MB였다. 그래서 전체 노트를 `/notes/[탭]`으로 떼어 냈고, 탭 화면에는 개념 목록만 남겼다(PR #2, 497KB).

## Consequences

- 탭 화면에서 전체 노트로 가는 링크는 `<Link>`가 아니라 `<a>`이다. `@panel/(.)[slug]` 가로채기가 `/notes/net`을 "탭 `notes`의 개념 `net`"으로 읽어 404가 나기 때문이다.
- 클라이언트 컴포넌트에 콘텐츠 필드를 더 넘기면 모든 탭 화면이 그만큼 무거워진다.
