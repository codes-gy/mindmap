# 완료 기록은 브라우저에만 두고, 바뀌지 않는 개념 id로 저장한다

계정도 서버도 없이 쓰는 페이지라서 완료 기록은 보는 사람의 `localStorage`(`mindmap-progress-v2`)에만 둔다. 키는 개념의 `id`(`<탭>/<슬러그>`)이고, 알아둘 것은 `<탭>/~<주제 키>`이다. v1은 `탭|주제|묶음|개념` 이름을 키로 써서 제목만 바꿔도 기록이 끊겼다. 그래서 PR #1에서 제목과 상관없는 id로 바꿨다.

## Consequences

- 한 번 배포한 개념의 `id`와 `slug`는 바꾸지 않는다. 기록이 사용자 브라우저에 흩어져 있어서 서버에서 한꺼번에 옮길 방법이 없다. 같은 id는 공유된 주소(`/net/tcp`)이기도 하다.
- v1 기록(`mindmap-done`)은 처음 접속할 때 브라우저가 `public/legacy-progress-map.json`을 받아 새 id로 옮긴다(`lib/progress/migrate.ts`).
- 기기나 브라우저가 다르면 기록이 공유되지 않는다. 나중에 서버 동기화로 바꿀 수 있도록 저장소를 `ProgressStore` 인터페이스 뒤에 두었다.
