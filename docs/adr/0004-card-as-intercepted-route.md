# 설명 카드는 개념 페이지 주소를 가로챈 라우트로 그린다

마인드맵에서 개념을 누르면 지도를 그대로 둔 채 설명 카드가 뜨고, 주소도 그 개념의 주소(`/net/tcp`)로 바뀌어야 한다. 그래서 parallel route(`app/[tab]/@panel`)와 intercepting route(`(.)[slug]`)로 같은 주소를 두 가지로 그린다(PR #1). 탭 안에서 이동하면 설명 카드가 뜨고, 주소로 바로 들어오거나 새로 고치면 개념 페이지가 열린다. 상태로만 여는 모달과 달리, 지금 보는 개념을 주소로 공유할 수 있다.

## Consequences

- 같은 개념이 `app/[tab]/[slug]/page.tsx`와 `app/[tab]/@panel/(.)[slug]/page.tsx` 두 곳에서 그려진다. 둘 다 `lib/view.ts`의 `resolve`를 쓴다.
- 가로채기는 탭이 바뀌는 이동을 처리하지 못한다. 그래서 다른 탭의 관련 개념 링크는 `<a>`로 개념 페이지를 연다.
