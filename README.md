# 마인드맵

Spring · CS 기초 · 네트워크 · 자료구조 · 알고리즘 개념을 마인드맵으로 정리한 백엔드 면접 학습 페이지입니다.

- 빌드 없이 동작하는 정적 사이트입니다. `index.html`을 브라우저로 열거나 아무 정적 호스팅에 올리면 됩니다.
- 개념 데이터는 `data/<탭>-<번호>.js`, 30초 답변·꼬리 질문·비교 표 같은 확장 데이터는 `data/x/`에 있습니다.
- 완료 기록은 보는 사람의 브라우저(localStorage)에 저장됩니다.

## 로컬 실행

```sh
python3 -m http.server 8000
# http://localhost:8000
```
